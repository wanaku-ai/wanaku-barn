# Get started with Wanaku Barn

Wanaku Barn is a set of utilities for [Wanaku](https://wanaku.ai/docs/next/). It provides the Wanaku CLI, the Wanaku Operator for Kubernetes and OpenShift, tools that administer Keycloak credentials, and the Barn backend that adds extensions to the Wanaku Admin UI.
