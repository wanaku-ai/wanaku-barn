# Manage integrations and data

The Barn backend stores integrations and data for Wanaku. You can use its features from the Wanaku Admin UI, the Wanaku CLI, and the REST API.

## Pages in this section

- [Service catalogs](service-catalogs.md): what a catalog contains and how Wanaku serves its tools.
- [Build and deploy a service catalog](build-a-service-catalog.md): create a catalog with the CLI and serve it to Wanaku.
- [Service templates](service-templates.md): create parameterized service catalogs.
- [Kamelet catalog](kamelets.md): store Kamelet definitions and serve them to Camel applications.
- [Run integrations in the cloud](cloud-run.md): run Camel routes and semantic routes in a cluster with `wanaku cloud`.
- [Data stores](data-stores.md): inspect the records in the backend data store.
- [Create a semantic router](semantic-routing-wizard.md): build a decision service with the Semantic Routers page.
- [Semantic router contract](semantic-router-contract.md): the routing definition and the catalog that Barn generates from it.
- [Audit trail](audit-trail.md): the durable record of changes to Barn resources.
- [Deployment debugger](deployment-debugger.md): inspect a deployment from the Admin UI.
