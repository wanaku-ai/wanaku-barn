# Use the Wanaku CLI

These pages are for users who manage Wanaku from the command line.

## Pages in this section

- [Install the Wanaku CLI](install.md): install the CLI from a binary, with JBang, or with `get-wanaku.sh`.
- [Authenticate the Wanaku CLI](authenticate.md): log in, manage tokens, and use tokens in CI/CD.
- [Inspect tools, resources, and prompts](capabilities.md): list what the MCP servers expose, and call a tool.
- [Forward MCP servers](forwards.md): connect Wanaku to other MCP servers.
- [Namespaces](namespaces.md): group tools and resources for each agent.
- [Manage evaluators with the CLI](evaluators.md): update evaluators at runtime and roll back revisions.
- [Shell completion](shell-completion.md): complete commands and options in bash and zsh.
- [Agent skills](agent-skills.md): the skills that teach coding agents how to use Wanaku.

All CLI commands use the Wanaku management API. To automate a task that the CLI does not cover, call the API directly.
