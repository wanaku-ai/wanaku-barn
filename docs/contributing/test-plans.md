# Test Plans

Test plans for execution by humans and AI agents have moved to
[wanaku-tests](https://github.com/wanaku-ai/wanaku-tests).

Follow, create, and update plans in that project under `plans/`, with reusable
procedures under `plans/common/` and environment setup under `plans/setup/`.
Follow the instructions in wanaku-tests for writing and running plans.
